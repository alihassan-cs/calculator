# Infix to Postfix Expression Evaluator

This project converts an infix expression into postfix notation using stacks in C++.

## Features

- Infix to postfix conversion
- Supports:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
- Supports brackets:
  - ()
  - []
  - {}
- Handles multi-digit numbers
- Handles variables
- Error handling:
  - Syntax errors
  - Logical errors
  - Division by zero
