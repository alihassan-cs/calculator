# Calculator Expression Evaluator

A C++ program that converts infix expressions to postfix notation and evaluates them using stacks.

## Features

- Infix to postfix conversion
- Postfix evaluation
- Variable support
- Multi-digit numbers
- Bracket validation
- Error handling
- Division by zero checking

## Supported Operators

- +
- -
- *
- /

## Supported Brackets

- ()
- []
- {}

## Example

Input:

```text
a + b * (c - d)
